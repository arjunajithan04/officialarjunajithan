# `01 / ABOUT`

> **I like to build things that matter.**

This repository contains my personal portfolio — a digital space where I bring
together my projects, experience, technical capabilities, experiments, and
the things I'm currently exploring.

But this isn't designed to be a static resume on the web.

The portfolio is built as an **interactive digital experience** where motion,
typography, interaction, content, and technology work together.

The project also includes a custom **Supabase-powered CMS**, allowing the
portfolio to evolve without constantly modifying the source code.
